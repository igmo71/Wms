# Обороты склада

## Результат

Оператор видит постраничную историю проведенных изменений остатков.

## Область работ

- Сервис возвращает обороты с фильтрами по периоду, складу, ячейке, SKU и номеру приходного или расходного ордера.
- По умолчанию экран показывает записи за текущий день.
- Таблица отображает дату, склад, ячейку, SKU, изменение, остатки до и после, а также тип документа-основания.

## Критерии приемки

- Обороты сортируются и разбиваются на страницы на сервере.
- Фильтр ячейки ограничен выбранным складом.
- Основание определяется по регистратору связанного движения. Для приходного и расходного ордеров отображается ссылка с типом, номером и датой без времени; для инвентаризации — её тип.
- Поиск по документу находит обороты приходных и расходных ордеров по номеру; инвентаризации без номера в него не входят.

## За пределами области

- Номер и переход к документу-основанию.
- Агрегация оборотов по периоду.

## Движения

- Отдельный экран показывает только проведенные движения, с фильтрами по периоду, складу, ячейке, SKU и номеру приходного или расходного ордера; по умолчанию — за текущий день.
- Каждая строка показывает источник, назначение, SKU и количество. Основание — ссылка на приходный ордер, расходный ордер или инвентаризацию, если у движения известен регистратор. Для ордеров ссылка содержит номер и дату без времени.
- Черновые движения в экран не включаются.
