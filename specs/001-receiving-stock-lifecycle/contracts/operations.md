# Контракты операций целевой приемки

Это поведение команд и чтения для Web, Mobile и интеграции 1С. Конкретные
HTTP-маршруты и DTO определяются при замене вызывающих интерфейсов.
Правила допуска и учета принадлежат [спецификации](../spec.md).
Контракт охватывает новую приемку и размещение, не устанавливая совместимость
с прежними операциями отбора, отгрузки, перемещения и инвентаризации.

## Общие соглашения

- Количество передается в учетной единице SKU с точностью до трех знаков;
  календарный срок годности передается датой без времени и часового пояса.
- Мутация содержит идентификатор запроса для повторного вызова. Повтор
  успешно принятой команды возвращает сохраненный результат без второго
  движения или события аудита.
- Чтение плана различает число `0`, неизвестное количество с причиной и
  последнюю ошибку сверки. Ошибка новой сверки не стирает последнее успешно
  известное числовое значение.
- Команды с проверкой показанного состояния принимают его ревизию; при
  изменении плана, LPN, признака SKU или остатка до записи возвращают конфликт
  и актуальное состояние для повторного решения.

## Источники 1С и ордер WMS

| Операция | Вход | Результат |
|---|---|---|
| Уведомление 1С или ручная сверка | `Ref_Key` либо WMS-ордер для сверки всех источников | Последнее прочитанное состояние источника, новая версия только при изменении содержимого, время и результат попытки; связанный план пересчитан без изменения факта и статуса. |
| Ручная синхронизация справочника | Вид справочника; пользователь с ролью `Manager` | Обновление импортируемых данных справочника из 1С; локальный признак срока годности SKU сохранен. |
| Поиск и выбор источников | Идентификаторы документов 1С | Их реквизиты, проблемы проекции, суммарный план по SKU и признак неполноты. Повтор одного источника не удваивает вклад. |
| Создание WMS-ордера | Склад, выбранные источники, идентификатор запроса | Собственный идентификатор ордера, закрепленные связи, агрегированный план и начальное состояние. Источник, уже закрепленный за другим ордером, дает конфликт. |
| Изменение связей | Ордер, источник, действие добавить/открепить, ревизия | Новый план и событие истории; факт и проведенные движения прежние. Права зависят от наличия проведенной LPN и статуса ордера. |
| Добавить SKU в состав ордера | Ордер, SKU из синхронизированного справочника 1С, ревизия, идентификатор запроса; оператор Mobile при подтверждении выбора либо менеджер Web | Уникальная строка с планом `0` при отсутствии вклада источников и непроверенным фактом; аудит без изменения зеркала 1С и складского движения. Повтор не создает вторую строку. |

Нечитаемый ответ не заменяет последнюю сохраненную версию. Успешно прочитанный
документ сохраняется и при проблемной строке; известные SKU других корректных
строк остаются доступны. Записи в 1С из приемки нет.
Роль `Administrator` сама по себе не разрешает ручную синхронизацию
справочников или менеджерские действия с проведенной приемкой; права
назначенных одному пользователю ролей складываются.

## Приемка и размещение

| Операция | Вход | Результат |
|---|---|---|
| Начало/повторное открытие цикла | Ордер, пользователь, место приемки при первом присоединении; для повторного открытия — менеджер | Состояние цикла, участники и закрепленное для новых LPN место приемки. |
| Открыть приемную LPN и сохранить ее позицию | Ордер, выданный код LPN, один SKU, абсолютное количество, дата либо `null`, ревизия | Сохраненная позиция и событие каждого изменения; без складского движения до закрытия. |
| Подтвердить нулевой факт SKU | Ордер, SKU из состава, ревизия, идентификатор запроса; оператор активного цикла | Числовой факт `0` и событие проверки без складского движения; при наличии действующей закрытой или открытой LPN этого SKU — отказ. |
| Отменить открытую LPN | LPN, ревизия, идентификатор запроса; владелец-оператор или менеджер | Статус отмены и событие истории без движения и изменения факта; LPN больше не блокирует завершение ордера. |
| Закрыть LPN | LPN с одним SKU и положительным количеством, ревизия, идентификатор запроса, подтверждение прошедшей даты при необходимости; менеджер может добавить необязательную причину | Попытка сверки источников, использованный план и предупреждение о сбое, факт после закрытия, движение прихода, остаток, оборот, аудит и квитанция в одной операции. Пустая или нулевая LPN отклоняется. |
| Разместить часть LPN | LPN, ревизия, количество, целевая ячейка, идентификатор запроса | Проведенное перемещение с исходным SKU и сроком, связью с LPN и новым доступным к размещению количеством. |
| Завершить ордер | Ордер, ревизия и идентификатор запроса | Новый снимок цикла плана и факта и статус «Принят» без складского движения; открытая LPN дает отказ. |

При закрытии LPN актуальный признак SKU проверяется сервером: положительное
количество при включенном признаке требует дату. Оператор закрывает LPN, если
совокупный факт этого SKU после закрытия не превышает известный план;
превышение или неизвестный план требует менеджера. Сбой свежей сверки сам по
себе не блокирует закрытие по последнему известному числу. Сохраненная дата
не удаляется при выключении признака SKU.
Если указанная дата срока раньше календарной даты закрытия LPN, сервер
требует явного подтверждения закрывающего и сохраняет его в событии закрытия.
Равная дата не требует подтверждения; прошедшая дата сама по себе не меняет
полномочия на закрытие.

Mobile по умолчанию предлагает состав ордера и дает явно переключить поиск
на весь синхронизированный справочник 1С, в том числе по наименованию без
штрихкода. Сканирование штрихкода всегда ищет во всем справочнике независимо
от области ручного поиска. Подтверждение выбора SKU вне состава добавляет
строку ордера;
для нее используется обычная открытая LPN и общее правило закрытия сверх плана.

## Менеджерские действия и чтение

| Операция | Вход | Результат |
|---|---|---|
| Изменить количество закрытой LPN | LPN, новое неотрицательное абсолютное количество, ревизия, идентификатор запроса | Разница проведена в исходном месте приемки, факт LPN и ордера обновлен. При наличии хотя бы одного размещения — отказ. |
| Предпросмотр удаления LPN | LPN | Собственные движения LPN и их обратные движения по исходным адресам; прогноз остатков с явным выделением отрицательных. Без записи. |
| Удалить закрытую LPN | LPN, ревизия предпросмотра, подтверждение возможных отрицательных остатков, идентификатор запроса | Атомарно проведены обратные движения, LPN помечена удаленной, ее действующий факт равен нулю; независимые перемещения, отбор и отгрузка не обращены. |
| Изменить признак SKU | SKU, значение, ревизия, идентификатор запроса | Новый локальный признак и запись истории до/после без изменения существующих дат и остатков. |
| Читать состояние и историю | Ордер, источник, LPN, SKU или фильтр отчета | Актуальные план/факт и расхождение отдельно от снимков завершений; версии 1С, события WMS, связи движений и остатки без даты для SKU с включенным признаком. |

Повторное удаление LPN и изменение количества уже удаленной LPN отклоняются.
Отрицательные остатки после обращения доступны в чтении по ячейке, SKU и дате.
Если после предпросмотра удаления изменились LPN, ее собственные движения или
затронутые остатки, подтверждение возвращает конфликт и новый прогноз.
