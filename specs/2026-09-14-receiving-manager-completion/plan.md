# План реализации

Статус: этапы 1–5 реализованы. Сборки Web, API, Android и проверка
соответствия модели миграции прошли. Документация обновлена. Остается ручная
приемка на данных склада и последующая заморозка спецификации.

1. **Режим приемки.** Добавить ReceivingIntegrationMode (Connected/Autonomous),
   для текущего внедрения выбрать Autonomous. Охватить все исходящие операции
   приходного ордера, сохранив чтение. Не разрабатывать перенос текущих операций.
2. **План и сверка.** Сохранить исходный план и отдельно показывать текущие
   данные 1С. В Autonomous не заменять план после импорта и не связывать этапы
   WMS со статусом 1С. Разделить информационные различия, количественные
   расхождения и необходи́мые блокировки (проведение, удаление, ошибки проверки).
   В Connected сохранить остальные правила сверки.
3. **Обычное завершение.** На общей серверной границе проверять количественные
   расхождения; объяснять необходимость решения заведующего в Web и Mobile.
   Сохранить свежий независимый checkpoint.
4. **Права и специальная команда.** Добавить Manager в инициализацию ролей,
   управление пользователями и доступ к штатным операциям. Разрешить специальную
   команду Manager и Administrator с серверной проверкой. Обязательная причина,
   актуальное решение, CommandExecutor, атомарные складские эффекты/аудит/receipt.
   Схему хранения решения изменить по необходимости, без переноса старых данных.
5. **Web.** Показать исходный план, текущий план 1С и факт, действие завершения
   с причиной и историю решения. Сохранить данные команды для неопределенного
   повтора. Не добавлять специальную команду в Mobile.
6. **Целевая проверка.** Просмотр и сборка затронутых проектов; короткий ручной
   сценарий по критериям спецификации, особенно 10 → 8 → 8 в обоих режимах.
   Автоматические тесты не добавлять/менять/запускать без согласования.
7. **Документация.** По мере реализации обновить текущие правила в docs.
   По завершении заморозить спецификацию, обновить реестр и удалить временный план.
