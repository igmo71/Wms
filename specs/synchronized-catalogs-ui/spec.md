# Справочники, синхронизируемые с 1С

## Результат

Оператор может просматривать в UI синхронизируемые из 1С склады, номенклатуру, штрихкоды, единицы измерения и направления доставки и получает явный результат ручного обновления.

## Объём

- Страницы предназначены только для просмотра и запуска существующей синхронизации с 1С, без ручного редактирования.
- Списочные импорты возвращают `ServiceResult` и передают вызывающему коду ошибки обращения к 1С и некорректного ответа.
- Номенклатура, штрихкоды и единицы измерения поддерживают поиск, серверную сортировку, пагинацию и отображение деактивированных записей.
- Направления доставки отображаются деревом по `ParentId`, без пагинации и поиска, чтобы всегда сохранялась полная иерархия.
- Номенклатура импортируется параллельными пакетами. Ошибка любого пакета делает результат всего импорта неуспешным, но уже сохранённые пакеты не откатываются; сообщение предупреждает о возможном частичном обновлении.
- Диагностические HTTP endpoints списочного импорта возвращают `502 Bad Gateway`, если импорт не смог получить корректные данные из 1С.

## Критерии приёмки

- Все пять страниц доступны из группы «Конфигурация».
- Каждая страница позволяет запустить импорт из 1С, блокирует повторный запуск и показывает индикатор выполнения до завершения запроса.
- После завершения ручного импорта страница показывает зелёное сообщение об успехе либо красное сообщение с причиной ошибки; список перечитывается только после успешного импорта.
- Штрихкод выводится вместе с номенклатурой.
- Для номенклатуры отображаются код, наименование, базовая единица и вес.
- Для единицы измерения отображаются основные реквизиты и коэффициент.
- Направления доставки показывают папки, элементы, комментарии и пометку деактивации.
