# Отправитель источников и мобильный экран документов 1С

## Цель

Один приходный ордер объединяет только документы 1С с одинаковым
идентификатором `Отправитель`, независимо от `Отправитель_Type`. Это сохраняет
однозначную принадлежность недостачи отправителю, включая перемещения между
складами. В мобильной приёмке документы 1С находятся на отдельном компактном
экране.

## Правила

1. При создании ордера из нескольких документов и при каждом последующем
   прикреплении сервер требует корректный ненулевой GUID отправителя. Все
   активные источники ордера имеют один и тот же GUID. Название и тип ссылки
   для сравнения не используются.
2. После первого проведённого LPN идентификатор отправителя закреплён за ордером
   навсегда, в том числе после открепления всех источников, удаления LPN и
   повторного открытия ордера. До первой проводки открепление последнего
   источника освобождает выбор отправителя.
3. Новая версия уже прикреплённого документа с другим или некорректным
   отправителем не принимается. Последняя успешная версия и текущий план
   сохраняются, а ошибка последней сверки видна оператору.
4. Одинаковый запрет действует для создания в Web и Mobile, а также для
   прикрепления в обоих каналах. Web предупреждает о конфликте в предпросмотре;
   команда повторно проверяет правило в транзакции.
5. Уже существующие ордера с разными отправителями не исправляются
   автоматически. Их следует выявить и разобрать отдельно до включения
   строгой проверки для ранее созданных ордеров.
6. На странице мобильного ордера нижняя кнопка с иконкой документа и подписью
   «1С» открывает список прикреплённых документов. Сканирование допустимого
   документа немедленно прикрепляет его и пересчитывает план; можно
   последовательно сканировать несколько документов. Ошибка остаётся на
   экране и не прикрепляет документ. «Готово» и системная стрелка возвращают
   к SKU, при этом «Готово» ничего не сохраняет дополнительно.
7. Каждая строка списка показывает «Номер · Дата» и
   «Наименование отправителя · Складская операция» без названий полей.
   Только что прикреплённая строка выделяется серым. Тап открывает остальные
   реквизиты; доступное по прежним правилам открепление остаётся на этом
   экране.
