# Проверка закрепления остатка

## Подготовка

Разработчик создаёт миграцию после изменения EF-модели. Перед применением агент проверяет её файлы и снимок модели.

```powershell
dotnet ef migrations add AddPickingRouteReservations --project Wms.Infrastructure/Wms.Infrastructure.csproj --startup-project Wms.WebApp/Wms.WebApp.csproj --output-dir Data/Migrations
```

## Сборка и проверка схемы

Из корня рабочей копии собрать решение, проверить модель EF и выполнить серверные тесты. Тесты старта проверяют приоритет среди двух готовых сборок и повтор команды.

```powershell
dotnet build Wms.slnx -nologo -v:minimal
dotnet ef migrations has-pending-model-changes --project Wms.Infrastructure/Wms.Infrastructure.csproj --startup-project Wms.WebApp/Wms.WebApp.csproj
dotnet test Wms.Tests/Wms.Tests.csproj --no-build
```

Для проверки ТСД использовать dev-контур. Завершить или отменить ранее начатые сборки, применить миграцию к dev-БД и запустить WebApi и ТСД из этой ветки.

```powershell
dotnet ef database update --project Wms.Infrastructure/Wms.Infrastructure.csproj --startup-project Wms.WebApp/Wms.WebApp.csproj --connection "<строка подключения к dev-БД>"
```

## Сценарии на ТСД

1. Подготовить остаток 10 в обычной ячейке, без другого доступного остатка, и две сборки с планом по 8. Начать «Живую очередь», затем «Собрать к дате». До обхода должно быть доступно 8 и 2, у второй сборки видно нехватку 6.
2. В отдельном сценарии оставить свободный товар в другом допустимом адресе. На ТСД сверить «Доступно» в «SKU» и «Маршрут», затем через «SKU» отобрать из свободного адреса. Проверить адрес факта и освобождённое количество. При недостаче в общей группе проверить, что её шаги исчезли у всех затронутых сборок. Когда факт покрывает план, открыть «Маршрут» и убедиться, что экран показывает «Отбор по маршруту завершён» и предлагает закрыть сборку.
3. Провести подпитку на 4 при непокрытом плане 6. После обновления доступно ещё 4, не хватает 2. Проверить, что другой маршрут не получил поступившие 4.
4. Принять отмену сборки без подтверждённого факта. Проверить свободный остаток сразу после команды, в том числе пока продолжается ранее начатая подпитка. При наличии факта проверить отклонение отмены до возврата.
