# Единое расположение колонок списков документов

## Результат

Списки складских документов используют одинаковый порядок основных свойств и
показывают только значимые моменты завершения работы. Номер документа остается
ссылкой, поэтому отдельная колонка действий не выводится.

## Общие правила

1. В начале идут `Номер`, `Дата`, `Склад`, `Статус`.
2. Для ордеров затем идут `Очередь` и `Складская операция`.
3. После общих свойств идут свойства конкретного документа.
4. Начальные и промежуточные технические моменты времени в списках не выводятся.
5. Последними идут завершенные процессы. В каждой такой колонке актуальное имя
   пользователя отображается первой строкой, а дата и время завершения — второй;
   новое имя не сохраняется в документе.

## Колонки

- Приходные ордера: `Номер`, `Дата`, `Склад`, `Статус`, `Очередь`,
  `Складская операция`, `Размещение`, `1С`, `Принято`, `Размещено`.
- Расходные ордера: `Номер`, `Дата`, `Склад`, `Статус`, `Очередь`,
  `Складская операция`, `Направление доставки`, `1С`, `Собрано`, `Отгружено`.
- Инвентаризации: `Номер`, `Дата`, `Склад`, `Статус`, `Провёл`, `Проведено`.
- Перемещения: `Номер`, `Дата`, `Склад`, `Статус`, `Тележка`, `Завершил`,
  `Завершено`.

Для расходного ордера завершением сборки считается переход в готовность к
отгрузке (`ReadyForShipmentBy`, `ReadyForShipmentAtUtc`).
