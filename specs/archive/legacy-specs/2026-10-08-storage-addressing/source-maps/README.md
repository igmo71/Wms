# Карты склада из 1С

Здесь сохранены 24 исходные XLS-выгрузки, предоставленные для планирования E1:
сводные карты, карты по ярусам и карты ворот и улицы. Имена и содержимое файлов
не изменены. Эти файлы нужны для проверки правил разбора адресов и предпросмотра
массовой загрузки; актуальность физической разметки проверяется отдельно.

Решения по адресации и оставшиеся вопросы находятся в
[спецификации E1](../README.md).
