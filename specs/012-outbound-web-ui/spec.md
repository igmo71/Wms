# Веб-интерфейс отгрузки

**Статус:** реализован веб-блок интерфейса.
**Задача:** [#42](https://github.com/igmo71/Wms/issues/42).

## Цель

Оператор и руководитель видят импортированные расходные ордера 1С и существующие
складские сборки в одном разделе «Отгрузка», по структуре навигации Приёмки.
Веб-интерфейс не создаёт новые РО WMS. Существующее создание сборок на ТСД и
правила Отбора и складского закрытия сохраняются.

## Сценарии

1. В разделе «Отгрузка» пользователь открывает «Документы 1С», находит РО по
   номеру, видит его статус, получателя, склад, время и результат последней
   проверки. Выбор документа показывает его сохранённые строки SKU и количества.
   Если документ привязан к сборке и её карточка доступна пользователю,
   номер ведёт к ней. Из карточки сборки можно открыть исходный документ.
2. Пункт «Ордера WMS» открывает существующий список сборок. Карточка показывает
   общий план и физический факт по SKU: равные количества выделены зелёным,
   расхождения — жёлтым. Черновик и подготовка без начатого Отбора нейтральны.
3. В карточке сборки строки отдельного РО 1С получают сравнение с его
   распределённым фактом только после закрытия сборки. До закрытия у документа
   нет самостоятельного факта; план WMS и текущие строки 1С остаются отдельными.

## Границы

- Список документов читает сохранённую проекцию последней синхронизации WMS,
  без запроса к 1С при открытии страницы. Ошибка последней проверки показана
  рядом с ранее сохранёнными строками.
- Новых команд создания, проведения, синхронизации или изменения РО 1С в этом
  блоке нет.
- Изменения ТСД, включая нижнюю навигацию, единицы, адреса и остатки SKU,
  выполняются следующим блоком.
