# Импорт структуры предприятия из 1С

## Результат

WMS хранит локальную копию справочника 1С `Catalog_СтруктураПредприятия`, чтобы впоследствии разрешать отправителей и получателей складских ордеров в единый `PartyInfo`.

## Объём

- Полный импорт получает весь небольшой справочник одним запросом к 1С и сохраняет его одним пакетным вызовом EF Core.
- Пакетное сохранение одним запросом определяет существующие записи и выполняет один `SaveChangesAsync`; параллельная и постраничная обработка не используются.
- Одиночный импорт обновляет подразделение по уведомлению 1С.
- `Ref_Key` отображается в `OrganizationalUnit.Id`, `Code` — в `Code`, `Description` — в `Name`, `DeletionMark` — в `DeletionMark`, `Parent_Key` — в `ParentId`.
- Пустой `Parent_Key` и `Guid.Empty` отображаются в `null`.
- Подразделения отображаются в UI единым плоским постраничным списком без визуализации `ParentId`.
- Страница поддерживает поиск по наименованию, сортировку по коду и наименованию, показ деактивированных записей и ручное обновление из 1С.
- Расширение `PartyService` и пакетный `PartyService.GetManyAsync` не входят в текущий объём.

## Критерии приёмки

- Полный и одиночный импорт возвращают `ServiceResult` и передают ошибки получения данных из 1С.
- Отсутствующее поле списка или отсутствующая запись одиночного импорта считаются ошибкой; пустой список является допустимым результатом.
- GET endpoint запускает полный импорт и возвращает `502 Bad Gateway` при ошибке ответа 1С.
- POST endpoint принимает уведомление об изменении, а фоновый обработчик выполняет одиночный импорт.
- Схема БД содержит таблицу `OrganizationalUnits` для всех полей доменной модели.
- Пользователь может открыть справочник «Структура предприятия», просмотреть его постранично и получить явное сообщение об успешном или неуспешном ручном обновлении.
