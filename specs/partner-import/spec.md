# Импорт партнёров из 1С

## Результат

WMS хранит локальную копию справочника 1С `Catalog_Партнеры`, пригодную для последующего использования партнёров в складских документах.

## Объём

- Полный импорт получает количество элементов через `$count` и загружает справочник пакетами по 1000 записей.
- Одновременно обрабатывается не более 10 пакетов; каждый пакет сохраняется независимо через отдельный контекст БД.
- Одиночный импорт обновляет партнёра по уведомлению 1С.
- `Ref_Key` отображается в `Partner.Id`, `Description` — в `Name`, `Code` — в `Code`, `DeletionMark` — в `DeletionMark`, `Parent_Key` — в `ParentId`.
- Пустой `Parent_Key` и `Guid.Empty` отображаются в `null`.
- Партнёры отображаются в UI плоским постраничным списком без визуализации иерархии `ParentId`.
- Страница поддерживает поиск по наименованию, сортировку по коду и наименованию, показ деактивированных записей и ручное обновление из 1С.
- Реализация `PartyService.GetPartnerAsync` не входит в текущий объём.

## Критерии приёмки

- Полный и одиночный импорт возвращают `ServiceResult` и передают ошибки получения данных из 1С.
- Ошибка любого пакета делает результат полного импорта неуспешным и предупреждает о возможном частичном обновлении; уже сохранённые пакеты не откатываются.
- GET endpoint запускает полный импорт и возвращает `502 Bad Gateway` при ошибке ответа 1С.
- POST endpoint принимает уведомление об изменении партнёра, а фоновый обработчик выполняет одиночный импорт.
- Схема БД содержит таблицу `Partners` для всех полей доменной модели.
- Пользователь может открыть справочник «Партнёры», просмотреть его постранично и получить явное сообщение об успешном или неуспешном ручном обновлении.
