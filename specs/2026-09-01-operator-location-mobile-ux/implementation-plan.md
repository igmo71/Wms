# План реализации

## Этап 1. Однозначные ячейки в WebApp

- Ввести один простой формат полного кода ячейки.
- Применить его в операционных фильтрах, селекторах, карточках и таблицах.

## Этап 2. Короткий мобильный интерфейс

- Упростить главный экран и убрать номера шагов.
- Заменить общие длинные подписи команд короткими глаголами.
- Заменить текст закрытия строки поиска крестиком.

## Этап 3. Прямой отбор

- Удалить отдельную кнопку нового движения.
- Выполнять создание чернового движения непосредственно с экрана количества.
- Сохранить повтор с тем же `ClientRequestId` при неопределённом результате.

## Этап 4. Прямая финальная отгрузка

- Убрать QR-код позиции из мобильной команды финальной отгрузки.
- Оставить просмотр итога и явное подтверждение списания и закрытия ордера.
- Проверять закреплённую позицию на сервере по данным ордера.

## Этап 5. Проверка

- Обновить текущий контекст продукта.
- Собрать затронутые проекты без создания и запуска тестов.
- Передать сценарии ручной проверки.
