# Остатки на складе

## Результат

Оператор может увидеть текущие остатки SKU по ячейкам хранения.

## Область работ

- Сервис `InventoryBalanceService` возвращает постраничный список остатков.
- Запрос поддерживает фильтры по складу, ячейке хранения и SKU, текстовый поиск, сортировку и пагинацию.
- В UI доступна страница «Остатки» с соответствующими фильтрами и таблицей.

## Критерии приемки

- Каждый остаток показывает склад, ячейку, SKU, код SKU, количество и время последнего изменения.
- Фильтр ячейки ограничивается выбранным складом.
- Таблица сортируется на сервере и отображает корректное общее число строк.

## За пределами области

- Агрегация остатков по складу или SKU.
- Резервы и расчет доступного к отбору остатка.
