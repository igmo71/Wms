**Input**: [spec.md](spec.md), [plan.md](plan.md), [research.md](research.md), [data-model.md](data-model.md), [contracts/receiving-workspaces.md](contracts/receiving-workspaces.md), [quickstart.md](quickstart.md)

**Organization**: один пункт — один ограниченный инкремент с краткой передачей результата. Сборку, тесты, запуск Web/Mobile и команды EF выполняет разработчик по [AGENTS.md](../../AGENTS.md); агент проверяет сообщённый результат и созданную миграцию. Автоматические тесты добавляются только для рисков нумерации, повторов, устаревшего предпросмотра и сохранения проведённого факта.

**Format**: `[P]` означает независимую работу в других файлах; `[USn]` связывает задачу со сценарием спецификации. Все пути указаны от корня репозитория.

## Dependencies & execution order

1. T001 → T002 → T003 → T004 → T005. Перед T003 разработчик создаёт миграцию; агент проверяет её до применения и дальнейшей работы. Применение и проверка среды принадлежат разработчику.
2. US1 (T006–T009) и US2 (T010–T013) требуют T005. После основы могут выполняться независимо; T009 не зависит от T006–T008, T010 и T011 работают в разных клиентах.
3. US3 (T014–T015) требует готовой Web карточки с номером (T010), чтобы не менять `Details.razor` одновременно.
4. US4 (T016–T020) использует список свободных документов из US1 и карточку после US3; T016 → T017 → T018, затем T019 → T020. T019 можно готовить параллельно с T016–T018 в отдельном `.razor` файле, но подключение T020 делается после обеих частей.
5. T021–T023 следуют за нужными реализованными сценариями. Каждая завершённая задача оставляет краткую передачу с изменениями, проверкой разработчика и остающимся риском.

## Implementation strategy

**MVP**: T001–T009 дают устойчивую нумерацию и две понятные страницы с поиском/связями. Затем T010–T013 доводят номер и время до обоих клиентов, T014–T015 разграничивают обязанности Web/Mobile, T016–T020 добавляют безопасное изменение состава. Документация и проверка завершаются T021–T023; пропуск поздних фаз не считается завершением всей спецификации.
