# Specification registry

Only active issues belong here. Current product and engineering rules live in
[`PROJECT_CONTEXT.md`](../docs/PROJECT_CONTEXT.md) and
[`ARCHITECTURE.md`](../docs/ARCHITECTURE.md); unfinished work lives in
[`ROADMAP.md`](../docs/ROADMAP.md). Read archived specifications only when a
current task needs their decision history.

## Active

None.

## Archive

[Accepted and earlier specifications](archive/README.md) are historical records,
not current requirements. Their contents remain available without crowding the
working registry.

## Lifecycle

Create substantial work under `specs/YYYY-MM-DD-<problem-slug>/` with one
outcome, scope, acceptance criteria, and genuine open questions. Normally only
one specification is active.

When accepted, move lasting rules to the appropriate current document, keep
unfinished work in `docs/ROADMAP.md`, and move the specification to `archive/`.
Remove temporary implementation plans from the active issue before archiving.
