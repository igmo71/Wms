# Количества и подпитка на экранах отбора

**Статус:** реализовано; ручная проверка ТСД ожидается.
**Задача:** [#46](https://github.com/igmo71/Wms/issues/46).
**Ветка:** `codex/016-picking-quantities-replenishment`.
**Дата:** 2026-11-17.

## Цель

Сборщик одинаково понимает количества на экранах «Отбор › SKU» и «Отбор ›
Маршрут» и по каждому SKU видит, нужно ли заказать подпитку, выполняется ли
она и можно ли уже отобрать оставшийся план. Число заданий подпитчику,
источники и история их выполнения сборщику не требуются.

## Количества

- На обоих экранах для SKU показываются «План», «Доступно» и «Факт» в его
  базовой единице. «План» — план сборки по SKU, «Факт» — подтверждённый отбор.
- «Доступно» — суммарное количество текущих шагов маршрута по этому SKU,
  которое можно отобрать сейчас в пределах оставшегося плана. Это не общий
  складской остаток. Например, при плане 5, факте 0 и двух доступных единицах
  отображается «План 5 · Доступно 2 · Факт 0».
- Карточка шага маршрута дополнительно показывает «В этой ячейке: N». Это
  количество относится только к конкретному шагу и может быть меньше общего
  «Доступно» по SKU.
- После каждого отбора и проведённого перемещения подпитки доступность и
  маршрут пересчитываются. Поступившую часть можно отбирать сразу, не дожидаясь
  выполнения всех заданий подпитчику.
- Когда маршрут ещё не рассчитан или его не удалось обновить, вместо
  недостоверного нуля для «Доступно» показывается «—».

## Подпитка для сборщика

- Длинное пояснение о недостающем количестве на карточке SKU заменяется
  количеством «Доступно» и компактным значком подпитки. Значок изображает
  коробку со стрелкой вниз; состояние передаётся цветом и доступным описанием.
- Синий значок — можно заказать подпитку по SKU. Нажатие заказывает все
  доступные предложения по этому SKU как одно действие сборщика. Если задания
  уже выполняются и появились новые предложения, действие обозначается
  «Заказать ещё»; число заданий сборщику не показывается.
- Жёлтый значок — подпитка заказана и ещё не начата; оранжевый — выполняется.
  При частичном поступлении «Доступно» увеличивается, а подпитка остаётся в
  состоянии выполнения, пока оставшийся план нельзя отобрать полностью.
- Зелёный значок «Готово» появляется только тогда, когда «Доступно» покрывает
  весь оставшийся план по SKU. Завершение заданий само по себе не означает
  готовность SKU к отбору.
- Если оставшегося плана нельзя отобрать, новых доступных предложений нет и
  поступление по заказанным заданиям больше не ожидается, показывается серый
  значок с перечёркнутой стрелкой. Нажатие показывает
  короткую подсказку «Сейчас подпитать нельзя». Доступную часть SKU при этом
  можно отбирать; вопрос о недостающем количестве остаётся для решения
  руководителя.
- Если по SKU одновременно есть выполняемые задания и новые предложения,
  показывается доступное действие «Заказать ещё». После заказа снова
  показывается текущее состояние выполнения. Если весь план уже подтверждён,
  значок подпитки не нужен.
- Отдельный раздел «Подпитки» в рабочем месте сборщика и ссылки на него
  удаляются. Очередь и детали заданий в рабочем месте подпитчика сохраняются.

## Надёжность заказа

Один заказ по SKU может создать несколько заданий подпитчику. Они записываются
как один результат команды, без частичного заказа. Повтор того же действия
после неопределённого ответа не создаёт дубликаты; предложения и доступность
перепроверяются перед записью. При неподтверждённом результате сборщик может
повторить ту же команду из карточки SKU.

## Приёмка

1. На экранах SKU и маршрута для одного SKU совпадают «План», «Доступно» и
   «Факт», а карточка маршрута отдельно показывает количество своего шага.
2. Частичное перемещение сразу увеличивает «Доступно»; сборщик может отобрать
   поступившую часть, пока остальная подпитка ещё выполняется.
3. Одно нажатие заказа по SKU оформляет все актуальные предложения; при
   повторе после неопределённого ответа задания не дублируются.
4. Значок отражает возможность заказа, заказанное, выполняемое, готовое и
   недоступное состояние; новые предложения во время выполнения дают
   действие «Заказать ещё».
5. Зелёное «Готово» появляется только при достаточной доступности для всего
   оставшегося плана. При отсутствии доступной подпитки серый значок
   показывает подсказку без длинного текста на карточке.
6. Сборщик больше не видит отдельный раздел «Подпитки»; подпитчик продолжает
   работать со своей очередью и заданиями.
