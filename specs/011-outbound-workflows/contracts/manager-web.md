# Web руководителя: операции и представления

Экран сборки WMS показывает **три разных состояния**: план WMS по каждому РО 1С и общий итог; физический факт WMS по ячейкам/срокам и общий итог; текущие данные каждого РО 1С. Отдельно показываются стадия складского закрытия и результат обмена по документу. РО 1С в Web не редактируется напрямую. Управление планом, распределением и исключениями ниже требует явной роли `Manager`; `Administrator` сам по себе недостаточен. Физический Отбор с Web не вводится: руководитель с ролью `Operator` действует через тот же складской сценарий ТСД.

| Действие | Ввод | Проверка и результат |
|---|---|---|
| Просмотреть сборку и обновить источники | `AssemblyId` | Получить текущие РО 1С, показать изменения строк и реквизитов, время/ошибку запроса, активные резервы, недостачи, Подпитки и состояние обмена. Нет складского движения. |
| Изменить план WMS после начала | РО 1С, строки SKU/количество, причина, ревизия сборки | Меняет только план WMS и аудит; фактический Отбор остаётся. Следующее закрытие снова требует свежей проверки 1С. |
| Утвердить распределение | По каждому общему SKU — количество для каждого РО 1С, причина/ревизия | Сумма равна факту WMS, по документу не выше его утверждённого плана. При недоборе общего SKU решение явно вводит Manager. До закрытия это ещё не складское движение. |
| Закрыть и отгрузить с расхождением | Ревизия сборки, просмотренные версии РО 1С, решение и причина | Повторная свежая проверка всех источников, жёстких блокировок и сроков. Один складской коммит, затем обмен по документам. Изменение склада, операции, статус не `КОтбору`, снятие проведения, пометка удаления или недоступность 1С не обходятся решением. |
| Разобрать недостачу | Группа ячейка–SKU–срок, решение, причина, ссылка на сообщение | При подтверждении — датированное корректирующее движение и снятие блока в одном сохранении; при ошибочном сообщении — снятие блока с аудитом без движения. Резерв факта не трогать. |
| Исправить проведённую Подпитку | Ссылка на шаг, группа срока, разница, причина | Новое корректирующее движение и аудит; исходный шаг остаётся неизменным. |
| Отменить незакрытую сборку | Решение, причина, ревизия | Требует нулевого факта/резервов после физических возвратов и завершённых начатых Подпиток. Возврат статусов 1С — отдельное состояние обмена с безопасным повтором. |
| Закрыть и отгрузить после складского закрытия | AssemblyId и новый идентификатор попытки | Обработать только неподтверждённые документы по сохранённым целям. Выполненный PATCH пропускается, ошибочный или неподтверждённый POST повторяется после сверки. Новые расхождения требуют решения Manager. |

Любая меняющая команда несёт идентификатор запроса, защиту от повтора и ревизию целевой сборки/решения. Web сохраняет идентификатор при неясном ответе. После закрытия разрешены лишь отдельные корректирующие движения и операции обмена; простая правка факта запрещена.
