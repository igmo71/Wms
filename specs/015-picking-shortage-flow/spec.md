# Единое подтверждение отбора и недостачи

**Статус:** реализовано одним инкрементом.

## Цель

Сборщик одной кнопкой подтверждает полный предложенный отбор либо фактически
найденное меньшее количество. Во втором случае система одновременно сохраняет
найденный факт и сообщение о недостаче, не предлагая тот же сомнительный остаток
ячейки повторно. Руководитель видит отдельные решения об остатке ячейки и об
отгрузке сборки с фактом ниже плана.

## Правила

- После сканирования ячейки предложенное количество остаётся исходным значением
  поля. Равное ему положительное количество подтверждает обычный Отбор.
- Меньшее количество, включая ноль, означает полный физический остаток данного
  SKU и срока в ячейке, ещё не отражённый в подтверждённом факте. Перед записью
  ТСД показывает предложенный отбор, свободный учётный остаток, найденный факт
  и величину недостачи. Отмена оставляет складское состояние без изменений.
- Подтверждение меньшего количества одной идемпотентной командой резервирует
  найденный положительный факт и блокирует разницу между свободным учётным
  остатком группы и найденным количеством. Сервер повторно проверяет ревизию,
  выбранную группу, доступность и подтверждённое пользователем ожидаемое
  количество. Ноль создаёт сообщение и блокировку без записи факта.
- После такой команды маршрут не предлагает заблокированную группу повторно;
  другие доступные ячейки и SKU остаются доступны. Обычное подтверждение
  количества меньше актуально предложенного сервер отклоняет с указанием
  подтвердить недостачу. Отдельная кнопка недостачи в Отборе удаляется.
- Решение руководителя по недостаче исправляет или освобождает остаток ячейки;
  оно само по себе не меняет план и факт сборки. При недоборе ТСД явно направляет
  к руководителю. Веб-карточка показывает, что руководитель должен сверить 1С,
  при общем SKU распределить фактическое количество между документами и
  закрыть сборку с меньшим фактом и причиной. Оставшийся товар можно добрать
  до закрытия.
- Подпитка и её отдельное сообщение о недостаче сохраняют нынешние правила.

## Проверка

Для ячейки с учётным свободным остатком 5 и потребностью 3 подтверждение 2
создаёт факт 2 и блокировку 3; повтор той же команды не добавляет факт и
блокировку. Маршрут не возвращает эту группу. Нулевой факт не создаёт запись
Отбора. Равное предложению количество сохраняет обычный путь. Решение по
остатку не снимает требование отдельно рассмотреть недобор плана сборки.
