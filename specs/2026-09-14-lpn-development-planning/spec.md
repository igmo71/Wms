# Планирование развития WMS вокруг LPN

Статус: Active — проект на обсуждении, реализация не разрешена этим документом.

## Результат

Подготовить на основе текущего кода единый обсуждаемый план развития для работы
в нескольких чатах: [DEVELOPMENT_PLAN.md](../../docs/DEVELOPMENT_PLAN.md).

## Границы

Обследование приёмки, размещения, остатков, топологии, сканирования, клиентов,
интеграции, прав, отчётов и связанных складских операций; порядок этапов,
критерии проверки, подтверждённые правила и проектные предложения.
База пересоздаваемая; перенос существующих данных не планируется.
Прикладной код и база не меняются. Frozen-спецификации не требуются.

## Критерии приёмки плана

- Есть карта подтверждённых исходным кодом зависимостей и точек изменения.
- У этапов есть результат, зависимости и условия завершения.
- Учтены совместимость существующих операций с LPN и конкурентное проведение.
- Согласованные требования отделены от предложений с устойчивыми ID.
- Следующая задача может продолжить работу без чтения всей переписки.
- Пользователь обсудил и принял план либо зафиксированы требуемые поправки.
